# Pillar 5 — Conversion (Posts 27–30)

**Job:** ask, clearly, once. By now the account has been useful ~26 times, so the ask is
earned rather than pushed.
**Product rule:** still no purchase CTA — there is nothing to buy. The conversion is
*create a free profile*. That is the only action we want.

## Post 27 — 今晚 5 分钟，帮你的猫做一件事

| Field | Detail |
| --- | --- |
| **Hook** | 「今晚 5 分钟，做完这件事你会睡得比较安心」 |
| **Pain point** | Owners know they should prepare and never do, because the task has no deadline. Give it one: tonight. |
| **Story** | A specific, tonight-sized task list: take one clear face photo (Post 8), write down the pet's distinguishing marks, put a contact route in place. Then it is done and you stop worrying. |
| **Feature** | **Free profile creation**, framed as the last step of a task the viewer already agreed with. |
| **Format** | 🎬 Video, 40s |
| **Footage** | Evening at home, the task being done, ending with a completed profile on screen |
| 🤖 AUTO | ✅ The final 12s: screen recording of a completed pet profile, the completion card at 100%, and the Share Center |
| 📱 PHONE | Evening lamp-lit shots: you photographing the cat, writing notes, cat settling to sleep |
| **On-screen text** | 0s `今晚 5 分钟` / 6s `1. 拍一张清楚的正面照` / 14s `2. 写下特征` / 22s `3. 建一个档案` / 32s `完成 ✅` / 37s `免费 · 不用信用卡` |
| **Caption** | Callback to Post 8 and Post 7 so long-time followers feel the payoff. Close with a real, plain ask. |
| **CTA** | 「主页链接 · 免费建档，今晚就做完 🌙」 |

## Post 30 — 我们的第一个月

| Field | Detail |
| --- | --- |
| **Hook** | 「MyPetLink 上线第一个月，说说实话」 |
| **Pain point** | None. This closes the loop and sets up everything after Post 30. |
| **Story** | Genuine numbers — however small. How many profiles were created, what people asked for most, what you are building next, what you got wrong. If the number is 40 profiles, say 40. A real small number beats a vague big claim. |
| **Feature** | The product's actual trajectory. |
| **Format** | 🎬 Video, 45s, face to camera |
| **Footage** | You talking, with a few screen inserts |
| 🤖 AUTO | ✅ Supporting screen inserts (dashboard, a profile, the Share Card) |
| 📱 PHONE | Talking head, same setup as Post 22 for visual continuity |
| **On-screen text** | 0s `第一个月` / 8s `X 个档案建好了` / 16s `问最多的：实体牌几时有` / 26s `接下来做：___` / 38s `谢谢你们 🐾` |

## After post 30

The natural continuations, in priority order:

1. **Real user stories** — once there are users worth featuring, with written consent.
2. **Smart Tag launch** — the moment ordering is switched on, this becomes the strongest
   content beat available. Post 23 and Post 26 have already promised it honestly, so the
   audience is primed rather than surprised.
3. **Seasonal** — CNY fireworks and pet anxiety, Raya travel and pet boarding, monsoon
   and lost pets. All high-intent Malaysian moments.
4. **Repost the winners** — whichever of Posts 7, 8, 9 saved best, remake as video.
