# Manual prototype review

Use this after `npm run xhs:inspect -- 001` and before anything is published.

- [ ] The first 2–3 seconds state one clear hook.
- [ ] Cover and subtitles are readable at phone size.
- [ ] No frame contains more than two short lines of primary text.
- [ ] Screen recordings pause long enough to understand the result.
- [ ] UI remains large enough after the 9:16 crop.
- [ ] There is no awkward silence or dead time.
- [ ] Every first-person story, amount, date, pet, and event is real and documented.
- [ ] No customer phone, email, address, notification, username, or face is visible.
- [ ] Safety Profile and Public Share Profile are named correctly.
- [ ] No GPS/location-tracking capability is implied.
- [ ] No Smart Tag purchase CTA appears while ordering is unavailable.
- [ ] CTA matches the post pillar and the current product posture.
- [ ] `制作样片` and all placeholder frames have been removed from the publishable export.
